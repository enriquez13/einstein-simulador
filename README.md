# Einstein · Calculadora de colaboración

React + Vite. No requiere backend (todo el cálculo es en el navegador).

## Uso local
```bash
npm install
npm run dev
```

## Reglas de precios
Edita `src/pricing.js` (precios por paquete, plazos, crédito y adicional).

## Despliegue en Vercel
1. Sube el proyecto a GitHub.
2. En vercel.com → *Add New Project* → importa el repo.
3. Vercel detecta Vite automáticamente (Build: `npm run build`, Output: `dist`). Pulsa *Deploy*.
